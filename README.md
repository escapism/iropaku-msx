## 操作方法
- カーソルキーまたはジョイスティックで上下左右に移動
- Z,X,C,V の各キーで、それぞれ対応した色に変化
- スペースキーまたはAボタン、Bボタンで順次色が変化

キャラクターと同じ色のフルーツを食べることができます。  
違う色のフルーツに接触すると、フルーツは逃げます。

制限時間内にすべてのフルーツを食べられればクリアです。
